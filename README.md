# RegistroAcadémico

Este proyecto implementa una clase `RegistroAcademico` en C++ que gestiona las notas y créditos de un estudiante. 
Permite calcular el promedio ponderado y verificar si cumple los requisitos académicos mínimos.

## Características
- Cálculo automático del promedio ponderado.
- Validación de créditos aprobados.
- Documentación generada con Doxygen.
- Compilación mediante CMake.
